# CLAUDE.md

Personal portfolio built with Next.js (App Router, TypeScript) and Tailwind CSS v4.

- Before any UI, style, or copy change, follow the `portfolio-design` skill.
- Before touching projects, the intro, links, or the resume, follow the `portfolio-content` skill.
- One page only: intro, projects, contact. The resume is `public/resume.pdf`, linked from
  the nav as `Resume ↗` and opened in a new tab. No resume page, no timeline.
- Light and dark mode via `next-themes`; use color tokens only, never hard-coded colors.
- Run `npm run lint` and `npm run build` before saying a change is done.
- Never invent personal facts; leave `TODO:` markers instead.
